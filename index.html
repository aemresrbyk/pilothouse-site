Built for running agents side by side

Every project gets a real terminal tab that starts your agent with the flags, model and effort you choose. Stop losing track of which one is waiting.

Tabbed, real terminals

One login shell per tab (node-pty + xterm.js), side by side in a grid if you like. A worktree tab gives a second agent its own git branch, so two never edit the same files.

Any agent, your own models

Claude Code, Codex, Antigravity, Gemini CLI or opencode per project. Pick the model and effort level from what your own account offers.

One Inbox

Everything your agents ask, with their own options as buttons (or press 1–9). Failed commands are listed apart, and you see each tab’s CPU and memory.

Hand-off between agents

Hit your plan’s limit? Continue with another agent. It starts with the last conversation, the changed files and the project memory.

History across agents

Claude Code and Codex conversations in one searchable list. Resume one, or hand that exact conversation to another agent.

Finds everything itself

On first launch it finds your agent CLIs and the projects they worked in. You pick the projects and the agent for each.

Talk to your agent.
Nothing leaves your computer.

Press ⌘⇧Space (Ctrl+Shift+Space on Windows and Linux) anywhere, or say “Hey Pilothouse”, and speak. Whisper large-v3-turbo transcribes it on your computer and types it into the active tab. Conversation mode reads the answer back, asks you to repeat words it wasn't sure about, and lets you approve with “yes” or “no”.

Install

macOS builds are signed and notarized by Apple. Every build updates itself.

brew install --cask aemresrbyk/tap/pilothouse
curl -fsSL https://raw.githubusercontent.com/aemresrbyk/pilothouse/main/install.sh | bash

Homebrew is for macOS; the script works on macOS and Linux (it installs the AppImage). On Windows, download Pilothouse-Setup-x64.exe; the build isn’t code-signed yet, so SmartScreen asks once (More info → Run anyway).
