Built for running agents side by side

Every project gets a real terminal tab that starts your agent with the flags you choose. Switch with ⌘1–9 and stop losing track of which one is waiting.

Tabbed, real terminals

node-pty + xterm.js, one login shell per tab. Open several per project — one for the agent, one for npm run dev. Tabs come back after a restart.

Any terminal agent

Claude Code, Codex, Gemini CLI or opencode, picked per project. The instructions tab edits the right file: CLAUDE.md, AGENTS.md or GEMINI.md.

Knows when you're needed

The tab dot pulses while the agent works, turns amber when it asks for approval and green when it's done — plus a macOS notification and Dock badge.

History you can search

Read every past conversation of a project with dates, search all of them with ⌘F, and reopen one in a click. Works for Claude Code and Codex.

Flags & quick actions

Toggle the flags you use per project. One-click /doctor, /compact, /init, plus "Review git diff", "Find bugs" and "Write tests".

CLAUDE.md, files & git

Edit instructions in-app, browse and preview project files, draft long prompts in a scratchpad, and see the branch plus modified-file count at a glance.

Talk to your agent.
Nothing leaves your Mac.

Press ⌘⇧Space anywhere — or say “Hey Pilothouse” — and speak. Whisper large-v3-turbo transcribes it on your Mac and types it into the active tab. Conversation mode reads the answer back, asks you to repeat words it wasn't sure about, and lets you approve with “yes” or “no”.

Install

Signed with a Developer ID and notarized by Apple, so it opens without Gatekeeper warnings. Updates itself.

brew install --cask aemresrbyk/tap/pilothouse
curl -fsSL https://raw.githubusercontent.com/aemresrbyk/pilothouse/main/install.sh | bash

These commands go live on launch day. Mac first — Windows and Linux are next. Your projects are imported from ~/.claude.json on first launch.
